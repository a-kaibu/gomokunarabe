# 五目並べ

ブラウザで遊べる一人用の五目並べです。CPU の強さを4段階から選べて、「自由ルール」と「連珠ルール（黒に禁じ手あり）」のどちらでも遊べます。スマホ縦持ちでも PC でも遊べます。

**▶ 遊ぶ: https://a-kaibu.github.io/gomokunarabe/**

## 特徴

- **2つのルール**: 禁じ手なしの自由ルールと、先手の黒だけに 三三・四四・長連 の禁じ手がある連珠ルール。連珠では禁じ手の点に × を表示し、置けないようにしています（五ができる手は禁じ手より優先、四三は OK、止められた三は三に数えない、など本式どおりに判定します）。
- **CPU の強さ**: 初級・中級・上級・達人。上級は数手先を読み、四追い（四を打ち続けて勝つ手順）も探します。達人は時間いっぱい深く読み、相手の四追いが残る手も避けます。CPU は Web Worker で考えるので、考え中も画面は止まりません。
- **待った**: いつでも自分の直前の手まで戻せます。CPU の考え中でも、勝負がついたあとでも使えます（Ctrl+Z）。
- **遊びやすさ**: スマホでは1回目のタップで仮置き、もう一度タップで確定（設定で変更可）。手数・座標の表示、棋譜（PC）、自動保存と続きから再開、ルール別・強さ別の成績。
- **演出**: 石を置く・取り消す・五連のアニメーションと、Web Audio で合成した効果音（音声ファイルなし）。
- ビルド不要の静的サイト（素の ES Modules）。

## 開発

```sh
python3 -m http.server        # http://localhost:8000 で起動
npm test                      # ルール判定（禁じ手）と CPU のテスト
npm run test:e2e              # ブラウザで実際に打つ E2E テスト（初回は npx playwright install chromium）
node tools/selfplay.mjs 3 2 6 # CPU 同士の対局（達人 対 上級 を6局）で強さの差を確かめる
```

main に push すると GitHub Actions（`.github/workflows/pages.yml`）がテストを実行し、通ったときだけ GitHub Pages に公開します。
